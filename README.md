# VoxForge (etapa 1)

Plugin VST3 de cadena vocal: HPF, compresor, EQ (graves/presencia/aire), de-esser,
saturación, doble/coro, delay y reverb. 13 presets (reggaetón, deep house, trap,
afrobeats, rap y coros).

## Compilar sin instalar nada (GitHub)
1. Crea un repositorio nuevo en github.com y sube todo el contenido de esta carpeta
   (incluida la carpeta oculta `.github`).
2. Entra a la pestaña **Actions** → **Build VST3 (Windows)** → espera ~10 min.
3. Abre la ejecución terminada y descarga el artefacto **VoxForge-VST3-Windows**.

## Instalar en Windows
Copia la carpeta `VoxForge.vst3` a:
`C:\Program Files\Common Files\VST3\`
Luego, en FL Studio: Options → Manage plugins → Find installed plugins.
En Ableton Live: Preferencias → Plug-ins → activar VST3 y re-escanear.
